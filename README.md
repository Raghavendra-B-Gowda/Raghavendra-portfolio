# Developer Portfolio

A modern, responsive, and dynamic personal portfolio website built by Raghavendra B. The portfolio is designed to showcase skills, projects, and educational background with smooth animations and interactive elements.

## Technologies Used

- **Framework**: [React](https://react.dev/) + [TanStack Router](https://tanstack.com/router/latest)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Animations**: [LottieFiles](https://lottiefiles.com/) (`@lottiefiles/dotlottie-react`)

## Features

- **Modern Glassmorphism UI**: Beautiful semi-transparent panels and dynamic backgrounds.
- **Interactive Skills Bar**: A draggable and auto-scrolling marquee of technologies.
- **Animated Loading Screen**: A full-page Lottie animation that plays on initial load.
- **Responsive Design**: Carefully crafted layouts that look great on both desktop and mobile devices.

## Getting Started

1. Clone the repository
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`
